# Amoeba documentation

- [amoeba-mcp](mcp-server.md): an MCP server that lets AI agents deploy and manage services on Amoeba.
- [Project README](https://github.com/dickyj-grc/Amoeba#readme): what Amoeba does, running it locally, and the roadmap.
